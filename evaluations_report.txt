Runtimes:
When we run the code in processgrid.py, with grid1costs.csv as an input
to runsearch(), Dijkstra's algorithm takes 0.00026 seconds while A*
takes 0.00027 seconds. With grid2costs.csv as an input to runsearch(),
Dijkstra's algorithm takes 0.00586 seconds while A* takes 0.00186
seconds. With grid3.costs.csv as an input to runsearch(), Dijkstra's
algorithm takes 0.00548 seconds while A* takes 0.00691 seconds. From
this we can see that A* isn't always faster than Dijkstra's algorithm,
as a lot of it depends on how accurate the estimated finish cost is.
On the other side, when the estimated finish costs is accurate A*
significantly reduces execution time.

Search space:

algorithm removed 1160 items while A* removed 335 items. With
grid3costs.csv as an input to runsearch(), Dijkstra's algorithm removed
1160 items while A* removed 1107 items. From this we can see that A*
usually uses less search space compared to Dijkstra's algorithm, as
generally less items are removed.
